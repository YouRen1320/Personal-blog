# Blog API 文档

## 基础信息
- 基础URL: `http://localhost:5000/api`
- 所有需要认证的请求都需要在请求头中添加 `Authorization: Bearer <token>`
- 所有请求和响应都使用 JSON 格式

## 认证 API

### 用户注册
```http
POST /auth/register
```

请求体：
```json
{
  "username": "string",  // 用户名
  "email": "string",     // 邮箱
  "password": "string"   // 密码
}
```

响应：
```json
{
  "user": {
    "_id": "string",
    "username": "string",
    "email": "string",
    "createdAt": "date"
  },
  "token": "string"  // JWT token
}
```

### 用户登录
```http
POST /auth/login
```

请求体：
```json
{
  "email": "string",     // 邮箱
  "password": "string"   // 密码
}
```

响应：
```json
{
  "user": {
    "_id": "string",
    "username": "string",
    "email": "string",
    "createdAt": "date"
  },
  "token": "string"  // JWT token
}
```

## 博客文章 API

### 创建文章
```http
POST /posts
```

请求头：
```
Authorization: Bearer <token>
```

请求体：
```json
{
  "title": "string",    // 文章标题
  "content": "string"   // 文章内容
}
```

响应：
```json
{
  "_id": "string",
  "title": "string",
  "content": "string",
  "author": "string",    // 作者ID
  "createdAt": "date",
  "updatedAt": "date"
}
```

### 获取所有文章
```http
GET /posts
```

响应：
```json
[
  {
    "_id": "string",
    "title": "string",
    "content": "string",
    "author": {
      "_id": "string",
      "username": "string"
    },
    "createdAt": "date",
    "updatedAt": "date"
  }
]
```

### 获取单篇文章
```http
GET /posts/:id
```

响应：
```json
{
  "_id": "string",
  "title": "string",
  "content": "string",
  "author": {
    "_id": "string",
    "username": "string"
  },
  "createdAt": "date",
  "updatedAt": "date"
}
```

### 更新文章
```http
PUT /posts/:id
```

请求头：
```
Authorization: Bearer <token>
```

请求体：
```json
{
  "title": "string",    // 可选
  "content": "string"   // 可选
}
```

响应：
```json
{
  "_id": "string",
  "title": "string",
  "content": "string",
  "author": "string",
  "createdAt": "date",
  "updatedAt": "date"
}
```

### 删除文章
```http
DELETE /posts/:id
```

请求头：
```
Authorization: Bearer <token>
```

响应：
```json
{
  "message": "Post deleted successfully"
}
```

## 错误响应

所有 API 在发生错误时都会返回以下格式的响应：

```json
{
  "message": "错误信息"
}
```

常见 HTTP 状态码：
- 200: 请求成功
- 201: 创建成功
- 400: 请求错误
- 401: 未授权
- 404: 资源不存在
- 500: 服务器错误

## 注意事项

1. 所有需要认证的接口都需要在请求头中添加 `Authorization: Bearer <token>`
2. 用户只能修改和删除自己创建的文章和评论
3. 创建文章和评论时会自动关联当前登录用户
4. 获取文章和评论列表时会自动填充作者信息
5. 所有时间字段都使用 ISO 格式
